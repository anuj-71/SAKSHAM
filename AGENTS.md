# AGENTS.md

## gstack

This project uses [gstack](https://github.com/garrytan/gstack) for enhanced agent workflows.

### Web Browsing
- **Always use the `/browse` skill from gstack for all web browsing.**
- **Never use `mcp__claude-in-chrome__*` tools directly.**
